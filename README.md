# ProductSphere

ProductSphere is a modern, high-performance product discovery and cart management application built for the Slingshot Expert Series.

## Tech Stack

- **Frontend:** Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS, Zustand, Apollo Client
- **Backend:** Node.js, GraphQL Yoga, Prisma ORM, PostgreSQL / SQLite
- **Accessibility:** WCAG AA Compliant (Semantic HTML, axe-core tested)

## Quick Start

1. Clone the repository and install dependencies:

   ```bash
   npm install
   ```
